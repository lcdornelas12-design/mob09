🗄️ 1. Memória Volátil (RAM) vs. Armazenamento Persistente

💡 Conceito-chave: quando declaramos variáveis em JavaScript (como let alunos = []), elas existem apenas na memória RAM do navegador. Se o usuário recarrega a página (F5) ou fecha o app, todos os dados somem. O LocalStorage resolve isso gravando os dados no disco do dispositivo sob o domínio da aplicação.

O LocalStorage é um banco de dados embutido do tipo Chave-Valor (Key-Value) presente em todos os navegadores modernos e WebViews móveis. Ele mantém as informações guardadas mesmo que o aparelho seja desligado.

🏗️ As 3 Camadas da Persistência Web

Camada 1

🖥️ Interface (DOM)

Campos de digitação (<input>) e visualização em tabela (<tbody>). É a ponta visual com a qual o usuário interage.

Camada 2

⚡ Estado em RAM

O array de objetos JavaScript (alunos = [{...}]). É rápido e mutável, mas totalmente volátil.

Camada 3

💾 Persistência (Disco)

O LocalStorage do navegador. Armazena a versão congelada em texto dos dados para restauração futura.

🌉 2. A Ponte Serializadora: JSON.stringify e JSON.parse

⚠️ A Regra de Ouro: o LocalStorage SÓ armazena Strings (texto puro)! Se você tentar passar um array ou objeto direto para o setItem(), o JavaScript converterá para "[object Object]", corrompendo irreversivelmente seus dados.

Para contornar essa restrição técnica, utilizamos as duas funções da biblioteca nativa JSON:

MétodoDireçãoO que faz na prática
JSON.stringify(objeto) RAM ➔ Disco Transforma o array/objeto estruturado em uma string de texto serializada pronta para o setItem.
JSON.parse(texto) Disco ➔ RAM Reconstrói a string textual do getItem, restaurando-a como array de objetos manipulável em memória.

💻 As duas funções centrais de sincronia

// 1. PERSISTIR: Salva a RAM no disco
function persistir() {
    localStorage.setItem(CHAVE, JSON.stringify(alunos));
}

// 2. CARREGAR: Restaura o disco para a RAM ao iniciar a página
function carregar() {
    const salvo = localStorage.getItem(CHAVE);
    if (salvo) {
        alunos = JSON.parse(salvo);
        // Recalcula o próximo ID incremental para evitar colisões
        proximoId = alunos.length ? Math.max(...alunos.map(a => a.id)) + 1 : 1;
    }
    listar();
}

⚙️ 3. A Arquitetura das 4 Operações (CRUD)

CRUD é o acrônimo universal da engenharia de software para as quatro operações fundamentais sobre qualquer base de dados:

C — Create

Criar / Inserir

Lê os valores dos inputs e insere um novo objeto no array com alunos.push({ id, ... }).

R — Read

Ler / Renderizar

Percorre o array com alunos.forEach() e gera dinamicamente as tags <tr><td> na tabela.

U — Update

Atualizar / Editar

Localiza o registro com alunos.find() e substitui os dados existentes pelos novos valores digitados.

D — Delete

Excluir / Deletar

Remove o elemento do array utilizando alunos.filter(a => a.id !== idAlvo).

🎯 A Técnica do Ponteiro de Edição (idEditando)

Para reaproveitar o mesmo formulário e botão tanto para cadastrar quanto para atualizar, usamos uma variável de controle chamada idEditando:

let idEditando = null; // null = cadastrando novo | número = editando aluno existente

function salvar() {
    if (idEditando) {
        // [UPDATE] Se há um ID ativo, atualiza o aluno existente em vez de criar outro
        const a = alunos.find(x => x.id === idEditando);
        a.nome = nome.value;
        a.email = email.value;
        idEditando = null; // Libera o modo de edição
    } else {
        // [CREATE] Se não há ID, adiciona como novo registro com ID sequencial
        alunos.push({ id: proximoId++, nome: nome.value, email: email.value });
    }
    nome.value = email.value = ""; // Limpa os campos
    persistir();
    listar();
}

🧩 4. Evolução de Esquema: Adicionando Novos Campos

💡 O Desafio do Desenvolvedor: sistemas reais mudam com o tempo. Adicionar um novo campo (como idade, telefone ou curso) exige uma intervenção cirúrgica e coordenada em 5 pontos exatos da aplicação, sem quebrar o que já existe.

📋 O Checklist Obrigatório de Manutenção

LocalO que deve ser feitoExemplo Prático (Campo Idade)
1. HTML Form Adicionar o novo <input> para captura <input id="idade" type="number" placeholder="Idade">
2. HTML Tabela Adicionar a nova coluna no <thead> <tr><th>ID</th>...<th>Idade</th><th>Ações</th></tr>
3. JS: Create Incluir a propriedade no objeto e na limpeza alunos.push({ ..., idade: idade.value }); e idade.value = "";
4. JS: Read Renderizar a célula <td> com proteção nula <td>${a.idade ?? "-"}</td>
5. JS: Update Preencher no editar() e atualizar no salvar() idade.value = a.idade || ""; e a.idade = idade.value;
🛡️ O Operador Nullish Coalescing (??): se você cadastrou alunos no passado e agora adicionou a coluna idade, esses alunos antigos têm a.idade === undefined. Se você escrever apenas ${a.idade}, a tabela exibirá feiamente o texto "undefined". Usar ${a.idade ?? "-"} faz o JavaScript exibir um traço caso o valor seja nulo ou indefinido!

📁 5. Entrada e Saída: Backup Físico com Blob e FileReader

O LocalStorage fica preso dentro do navegador daquele computador específico. Para transferir dados entre máquinas ou criar cópias de segurança (backups), implementamos rotinas de exportação e importação física de arquivos .json:

📤 Exportação de Arquivos com Blob

function exportar() {
    // Converte o array da RAM em texto identado legível
    const texto = JSON.stringify(alunos, null, 2);
    // Cria um arquivo binário em memória virtual (Blob)
    const blob = new Blob([texto], { type: "application/json" });
    // Cria um link temporário invisível e força o download
    const a = document.createElement("a");
    a.href = URL.createObjectURL(blob);
    a.download = "alunos.json";
    document.body.appendChild(a);
    a.click();
    a.remove();
    URL.revokeObjectURL(a.href);
}

📥 Importação Segura com FileReader e Validação

function importar(evento) {
    const arquivo = evento.target.files[0];
    if (!arquivo) return;

    const leitor = new FileReader();
    leitor.onload = () => {
        try {
            const dados = JSON.parse(leitor.result);
            // Defesa de integridade: checa se o conteúdo é de fato uma lista
            if (!Array.isArray(dados)) throw new Error("O arquivo não contém uma lista válida.");

            alunos = dados;
            proximoId = alunos.length ? Math.max(...alunos.map(a => a.id)) + 1 : 1;

            persistir();
            listar();
            alert("Base de dados importada com sucesso!");
        } catch (e) {
            alert("Arquivo corrompido ou inválido: " + e.message);
        }
    };
    leitor.readAsText(arquivo);
}
💡 Vantagem Estrutural: repare que as funções persistir(), exportar() e importar() não precisam ser alteradas quando você adiciona novos campos (como idade). O formato JSON serializa e restaura o objeto integralmente, qualquer que seja a quantidade de propriedades!
